# Training data reference

The source JSONL files are intentionally not duplicated into this prototype directory. Training accepts an explicit dataset path and records the source filename and SHA-256 in the model artifact and evaluation report.

The current artifact was trained from:

- `routing_dataset_100k_valid_only.jsonl`
- 86,967 audited valid rows
- SHA-256 `bca11574006fac48d17f1efb67cd471822911e366b9a580755b68964499aa30e`

The optional contextual slice was:

- `routing_dataset_multiturn_with_models.jsonl`
- 8,284 rows
- 7,829 rows overlapped the primary dataset and were excluded from the novel slice
- 455 non-overlapping rows remained

The equal-level file, `routing_dataset_100k_valid_balanced_equal_levels.jsonl`, was trained as a controlled challenger. It contains 66,560 rows. It was not selected because it performed worse than the full audited model on both the common primary test set and the same 455-row novel multi-turn slice. Results are recorded in `reports/experiments/champion_selection.md`.

Other supplied files were treated as source/audit variants rather than independent test evidence. The prompt-free aggregate audit in `reports/dataset_audit.*` confirms that the four multi-turn files are one 8,282-prompt metadata family, not four independent sources. They were not combined blindly because overlapping generated prompts would leak near-identical examples between training and evaluation.

The promoted model adds two deterministic, half-weight prompt-envelope views for
each train-split row. These views are produced in memory and are not published as
training data. Validation, test, and external rows remain unmodified. The public
`metamorphic_routing_cases.jsonl` file contains only generated regression cases
derived from the already-public adversarial suite; it is never counted as
independent evidence.

Do not treat the multi-turn file as a fully independent benchmark. A production benchmark must be assembled from representative requests that were not generated by the same prompt-generation process.

`reports/external_dataset_evidence.json` records this conclusion without including
prompt content. The external-generalisation release gate requires an independently
reviewed evidence file whose exact SHA-256 is approved in the release policy and
whose dataset digest/count match the training report. Increasing the sample count
with more output from the same generator cannot satisfy that gate.
